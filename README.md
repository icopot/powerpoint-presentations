# powerpoint-presentations

This repository contains a collection of presentations created by me using Microsoft PowerPoint.

## Repository Contents

1. **`thesis.ppt`**: Bachelor's thesis presentation focused on building the front-end for a medical web application.
2. **`accounting-presentation`**: Presentation created for a corporate accounting course, analyzing a selected company's organizational structure and its three core financial statements (*Income Statement*, *Balance Sheet*, and *Cash Flow Statement*).
